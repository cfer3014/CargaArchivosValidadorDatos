## Pasos para Usar

### 1️⃣ Carga de Archivo
- Arrastra y suelta un archivo CSV o Excel
- O haz clic en "Seleccionar archivo"

### 2️⃣ Procesamiento Automático
- La aplicación procesará los datos automáticamente
- Verás un indicador de carga

### 3️⃣ Visualización de Resultados
- **Cards**: Resumen de métricas principales
- **Gráficas**: Visualizaciones interactivas
- **Tablas**: Datos detallados con ranking

### 4️⃣ Descarga de Reporte
- Haz clic en "Descargar Reporte Excel"
- Se descargará un archivo con 4 hojas de análisis

## 📋 Formato de Datos Esperado

Tu archivo debe tener estas columnas:
- **Cliente**: Nombre del cliente
- **Producto**: Nombre del producto
- **Monto**: Cantidad de dinero
- **Fecha**: Fecha de la transacción
- **Tipo**: Debe contener "Compra"

### Ejemplo:
```
Cliente,Producto,Monto,Fecha,Tipo
Juan García,Laptop,1200.00,2024-01-15,Compra
María López,Mouse,25.50,2024-01-16,Compra
```

## 🆘 Problemas Comunes

**El archivo no se carga**
- Verifica que sea CSV o Excel
- Revisa que tenga las columnas requeridas

**No veo los resultados**
- Espera a que termine de procesar
- Verifica la consola del navegador

**El reporte no descarga**
- Intenta nuevamente
- Verifica la configuración del navegador
